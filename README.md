# Data Validation System

## Overview

This project is a desktop application built in Java using Swing for the Advanced Programming II module at Gauteng City College. The system captures personal information through a graphical interface and validates every field before it is accepted, giving the user clear, immediate feedback when input is invalid.

## Fields Captured

* Name and Surname
* ID / Student Number
* Date of Birth
* Gender
* Contact Number
* Email Address

## Validation Checks

Each field is checked using one or more of the following, as appropriate:

* Presence check, confirming the field has not been left empty
* Type check, confirming the field contains the correct kind of data
* Length check, confirming the entry meets a minimum or maximum number of characters
* Format check, confirming the entry matches an expected pattern, such as a valid email address
* Range check, confirming numeric values fall within a sensible range
